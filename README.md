# Pinhal Cabin

Site para o anúncio de Airbnb de uma cabana A-Frame na floresta: flythrough da cabana ao fazer scroll, cômodos, mapa e pedido de datas.

**Ver online:** https://cabana-gamma.vercel.app

![Página inicial da Pinhal Cabin](screenshot.jpg)

## Tecnologias

- HTML, CSS e JavaScript puro (site estático, sem framework)
- Animação de flythrough controlada pelo scroll
- Publicado na Vercel

## Correr localmente

Na pasta do projeto:

```bash
python3 -m http.server 8080
```

## Reservas

A página `reservar.html` é uma **demo**: as datas ficam só no `localStorage` do browser. Não há backend nem pagamento.
