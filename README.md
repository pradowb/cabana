# Pinhal Cabin

Site estático da cabana A-Frame: flythrough no scroll, cômodos, mapa e pedido de datas.

## Correr localmente

Na pasta do projeto:

```bash
python3 -m http.server 8080
```

## Reservas

A página `reservar.html` é uma **demo**: as datas ficam só no `localStorage` do browser. Não há backend nem pagamento.
